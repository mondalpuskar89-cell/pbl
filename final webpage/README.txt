CAMPUSCONNECT — ANIMATED PROFESSIONAL DESIGN

1. Stop the old server: press Ctrl + C in PowerShell.
2. Extract this ZIP into a NEW folder.
3. Open that extracted folder in VS Code.
4. Install: py -m pip install -r requirements.txt
5. Run: py app.py
6. Open: http://127.0.0.1:5000
7. If old styling remains, press Ctrl + Shift + R.

New design: animated hero, floating icon, entrance animations,
hover effects, gradient buttons, modern forms and responsive layout.
Copy your old data/*.csv files into the new data folder if you want
to preserve existing events and student records.
